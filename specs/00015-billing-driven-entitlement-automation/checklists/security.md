[Ambiguity, FR-002 / contract Error invalid_signature] <!-- Evaluator: Covered by spec.md FR-002 (missing/malformed/mismatched each rejected inline, no state change) + contract Error invalid_signature {reason: missing|mismatch} / stale_timestamp / validation_error -->
